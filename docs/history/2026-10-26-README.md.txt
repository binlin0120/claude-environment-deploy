## 这份教程怎么用

**更新于 2026-10-26。当前为草稿，还没在新电脑上从头到尾完整跑过。**

这份教程记录我们配置 Windows 虚拟电脑的过程：先建好 Hyper-V 虚拟机，再配网络和 AdsPower 专用浏览器环境，最后以 Claude 为例检查应用能不能正常使用。

## Codex 做什么，你需要做什么

先准备一台能正常进入 Windows 的电脑，装好并登录 Codex，让它能正常联网运行。接下来，技术步骤尽量交给 Codex；账号、购买和需要本人决定的事情由你处理。

| 阶段 | Codex 负责 | 你需要做的事 |
| --- | --- | --- |
| 检查电脑 | 检查 Windows 版本、内存、磁盘、Hyper-V 和已有软件，判断哪些能复用、哪些条件还缺 | 告诉它想用网页、桌面端还是完整虚拟机方案；按实际提示确认权限 |
| 准备虚拟电脑 | 核对官方安装来源、准备创建计划、创建虚拟机；有操作工具时继续协助安装 Windows | 处理 Windows 许可和本人登录；确认必要的系统盘写入及物理电脑重启 |
| 配置网络 | 先检查已有服务；需要新服务时阅读供应商说明，按实际产品配置、排错和测试 | 按需选择服务、注册、付款；把所选服务的官网和公开教程交给 Codex |
| 配置 AdsPower | 有可用操作工具时安装或复用软件，配好固定专用环境并检查设置 | 登录你自己的 AdsPower 账号，不必因为接口不可用就升级付费 |
| 使用 Claude | 打开官方页面和应用，检查登录后的网络及连续对话，记录结果 | **先在 AdsPower 专用环境里登录 Claude，再打开桌面端**；桌面端若要求登录，再由你完成 |
| 处理卡点 | 排查错误，说明卡在哪一步、缺什么工具以及接下来怎么做 | Codex 无法操作某个界面时，按它说明点击；遇到验证码、身份核验或付款，由你本人完成 |

**目前这份包还不是全自动安装器。**三个辅助脚本能检查电脑、创建一台尚未安装 Windows 的关机虚拟机，以及检查当前环境的网络出口。Windows 安装、网络、防火墙和 AdsPower 的后续配置，需要 Codex 结合现场权限与操作工具继续做，整套流程还没在新电脑上跑通验证。缺少工具时，它应明确告诉你需要点击哪一步，不能把没做的步骤算成完成。

当前脚本把文件位置固定在 `D:\Codex`。新电脑没有可用 D 盘时，不建议使用本版完整包，先停止部署，不为此重新分区或临时改写脚本。密码和验证码在本机官方页面输入，不用发到聊天里。

## 网站只是参考推荐，不用照着全部购买

我们用到和参考过的网址都放在 [工具和购买入口](docs/采购链接与致谢.md)，每个链接旁边都有用途说明。VPS 是租来的远程服务器，现成网络服务是供应商配好的连接服务，住宅 IP 是某类网络出口；先确定需要哪一种，再决定是否购买。

**这些入口只是参考推荐，不是指定商家，也不是必买清单。你已经有可用服务，就让 Codex 先检查能否复用；你也可以自己找其他供应商。**选好后，把它的官网和公开部署教程交给 Codex 核对，再按实际产品配置。下载、安装、配置和排错尽量交给 Codex，服务选择、续费和付款由你本人决定。

这里部署的是 Claude 的客户端和使用环境，Claude 模型仍运行在服务商处。VPS（租来的远程服务器）、住宅 IP 和指纹浏览器都不是官方使用前提。代理出口不能代替实际地区及账号资格，使用前核对 [官方支持地区](https://www.anthropic.com/supported-countries)。

## 每次使用前先检查一下

建议在准备使用的同一个 AdsPower 专用环境里打开 [Claude 网络检测页](https://ip.net.coffee/claude/)，看看出口、DNS、WebRTC 和时区是否与自己的配置一致；异常或检测不完整时先排查，再使用 Claude。这是第三方检测页，绿色提示和评分只是参考，不能证明账号或桌面端已经可用。

另有 [claude-switcher](https://github.com/YOURSJEYO/claude-switcher) 可作参考：Windows 测试版能定期检查代理状态，异常时关闭 Claude 桌面进程。我们没在这套环境里安装使用；它不保护 AdsPower 网页，也不代替防火墙。想了解用途和限制，先看 [使用前检测与可选防护](skills/claude-environment-deploy/references/使用前检测与可选防护.md)，再自行决定，不需要为了照着教程就安装。

## 先看自己的电脑能不能用

完整方案面向有可用 D 盘、硬件支持 Hyper-V 且资源足够的 Windows x64 电脑，也就是使用 Intel／AMD 常见 64 位处理器的电脑。**没有 D 盘，不建议使用这套包。家庭版要使用完整 Hyper-V 路线时，先检查硬件和资源，再决定是否使用已有专业版升级许可或购买升级；完成升级和激活后复查 Hyper-V，不在家庭版上直接硬装。** 内存、磁盘和现有软件也要现场检查，不能只看系统版本。

我们的主机是 Windows 11 专业版、AMD Ryzen 7 7800X3D、约 32 GB 内存；虚拟机使用 4 个虚拟处理器、4～8 GB 动态内存。这是使用环境说明，不是要求别人买同样的电脑。哪些情况可继续、哪些要先处理，以及具体处理方法，见 [适用电脑与操作前检查](skills/claude-environment-deploy/references/适用电脑与操作前检查.md)。

**教程和 Skill 都只能作为参考。一键执行有风险，其他电脑的整套流程待验证。** 系统组件、软件、网络和防火墙的变更，可能需要重启、短时断网或影响已有软件，也会占用磁盘空间。先保存工作、备份重要数据，让 Codex 检查并说明这台电脑的计划，再按本人同意的范围执行。

## 怎么交给 Codex

解压到 D:\Codex 下，用 Codex 打开这个文件夹，然后复制：

```text
请读取这个文件夹的 README.md，以及
skills/claude-environment-deploy/SKILL.md，按 Skill 帮我部署。
我选择完整隔离方案：Hyper-V＋来宾网络＋AdsPower 固定专用环境。
先在该环境中由我登录 Claude，再打开桌面端 Claude。
浏览器和桌面端分别验证连续对话，不用一个的结果代替另一个。
先做只读检查，再按已确认的范围自动执行；缺少的条件一次说明清楚。
先读“适用电脑与操作前检查”，报告主机版本、处理器类型、虚拟化、
空闲内存、D 盘空间和已有软件。没有可用 D 盘就建议停止使用本包；
家庭版选择完整 Hyper-V 路线时再说明专业版升级途径和费用，升级、付款和重启要在我同意后进行。
没有实际测过的组合写“待验证”，先说明一键执行风险，不保证一次成功。
账号登录、验证码和付款时停在本机页面让我本人完成，完成后继续。
所有任务文件放 D:\Codex，必要的主机 C 盘系统写入、重启及主机网络修改先说明。
使用我提供的官方供应商资料，不购买未选服务，不覆盖现有虚拟机和代理配置。
请分别报告实际完成、实测通过、未测和需要我处理的事项。
```

如果只想在自己的电脑上使用 Claude，把上面的“完整隔离方案”改成“本机基础路线”，再写清楚要用网页、桌面端还是 Claude Code。基础路线按实际需要安装；如果照着我们的完整方案做，就要把 AdsPower 也配好、测好。

以后发布到 GitHub，别人可以直接把仓库网址交给 Codex，让它先读 README，再把需要的文件下载到 D:\Codex，按教程操作。它需要能读取网页、运行命令；涉及点按钮的步骤，还需要能操作桌面的工具。你也可以直接让它读取解压后的 Skill，不用先安装到 C 盘。

如果希望 Codex 自动找到这个 Skill，可以按 [Codex 官方技能说明](https://developers.openai.com/codex/skills) 安装。默认用户目录可能在 C 盘；支持项目内安装的环境，也可以按官方说明放到项目的 .agents/skills 目录里。这份草稿没有替你安装 Skill 或插件。

## 自动化到什么程度

| 步骤 | 包里已经有的内容 | 还取决于什么条件 |
| --- | --- | --- |
| 前提检查 | 基础信息检查脚本 | Codex 还要补查 D:\Codex 写入权限、CPU 架构、已有虚拟机和相关软件 |
| Hyper-V 创建 | 参数化脚本，默认仅显示计划 | 合法 ISO、现有交换机、适用系统和明确创建授权 |
| Windows 首次设置 | Skill 的逐步流程 | 本人处理许可、登录及必要设置 |
| AdsPower 专用环境 | 安装、复用固定环境、代理衔接、WebRTC/语言/时区/内核核对和独立验收 | 可用的界面控制；本人登录 AdsPower，按当前套餐核对接口能力 |
| VPS / 网络服务 | 参考链接、文档审查和部署流程 | 本人按需选购或提供已有服务；Codex 按实际供应商和版本实施 |
| Claude 网页到桌面端 | 先在 AdsPower 登录 Claude，再打开桌面端；若提示登录，按官方流程完成并独立验收 | 本人账号和实际操作工具，不假定桌面端自动继承浏览器登录 |
| 出口检查 | 两个新 HTTPS 请求，只输出国家和状态 | 在正确环境执行，另测浏览器及应用 |
| 断线保护 | 专用来宾设计、回退及故障测试要求 | 针对现场网卡/程序制作规则并真实测试 |

压缩包里有教程、给 Codex 看的 Skill，以及三个辅助脚本。我们还没拿一台新电脑从头跑完整套流程，所以目前只能按草稿使用。网络和防火墙要按每台电脑的情况配置，包里也没有放原电脑的账号或私有配置。

## 草稿状态和后续验证

仓库名为 `virtual-pc-setup`，可以先以“草稿／待实测”的状态公开分享。使用许可尚未另行选择，不宣称已采用某种开源许可证。后续找一台新电脑，用不含真实账号资料的测试环境完整跑一遍。测过以后，把适用系统、版本和结果写清楚。公开仓库只放教程和通用脚本，Windows 镜像、商业安装包、私有日志和账号配置都留在自己电脑上。

致谢是感谢作者分享方法；这份教程由我们自己整理，遇到问题也由我们自己核对和维护。
