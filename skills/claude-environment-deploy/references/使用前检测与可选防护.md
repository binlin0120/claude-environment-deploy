# 每次使用前的检查与可选防护

## 先在准备使用的浏览器里检查

本套流程要求：配置、保存并打开目标 AdsPower 专用环境后，必须在同一个实际窗口先打开 [Claude 网络检测页](https://ip.net.coffee/claude/)，完成本次检查，确认与预期一致、无待处理异常后，才打开 Claude 网页并由本人登录。首次部署、每次使用、重开环境、网络恢复、重启或更新相关软件后，都重新检查，不沿用旧结果。用户明确选择普通浏览器的本机路线，在实际准备使用的浏览器里完成同一个指定检测，不必为检测单独安装 AdsPower；不能因工具只能控制普通浏览器而擅自改掉已选 AdsPower 路线。

这个页面会检查访问 Claude 等网站时的网络出口、地区和网络属性，并提供 DNS、WebRTC、时区、语言及连通性结果。DNS 是把网址解析成网络地址的过程；WebRTC 是浏览器的实时通信功能，可能走与普通网页不同的连接。

使用时按这个顺序：

1. 从目标电脑的 AdsPower 管理界面启动已保存的固定环境，确认实际窗口对应它。在同一窗口先打开 https://ip.net.coffee/claude/，等待本次检测完成；在本机目视核对当前 IP（网站看到的网络出口地址）、国家地区、网络属性，以及 DNS、WebRTC、时区等可见结果是否与预期配置相符。
2. 关键出口结果缺失、检测页打不开或超时、存在待处理异常，或无法控制和确认目标窗口时，暂停依赖它的 Claude 打开与使用步骤，先排查。工具做不到时，具体交代本人从哪个环境打开哪个网址、核对哪些结果，再由本人确认非敏感结论；本人报告须标注来源，不能写成 Agent 已独立验证。不静默跳过，不改普通浏览器，不自行改用其他检测方式；其他独立且已获授权的工作继续。
3. 本次检测完成、结果与预期相符且无待处理异常后，才在同一窗口打开官方 Claude 网页，由本人完成必要登录；如果还要使用桌面端，再打开它并按官方提示完成登录。已登录的继续用原环境，不必每次退出重登，也不清空或迁移会话。
4. 桌面端仍要单独检查实际网络和新对话，不能拿浏览器的结果替它通过验收。

运行记录只保存本次检测时间、匿名环境代号、检测完成状态、非敏感结论和待处理异常，不保存真实 IP 或带真实地址的截图。

这是第三方检测工具，评分和绿色提示供参考，不要求所有评分绿色。它没有验证账号资格、模型回复或连续聊天，也不能保证账号安全；网页的“可用”不等于 Claude 已经能正常聊天。DNS 或 WebRTC 没有结果不等于没有泄漏，应说明覆盖限制并核对原因，不能擅自判为通过。这一页还不能替代完整的 IPv6 检查，IPv6 是另一套网络地址。

检测会向网站和相关探测服务发出网络请求。公开前端代码还会把访问 Claude、Cloudflare 和国内探测站点时取得的三类出口地址，自动发送到检测站的 `/api/session` 接口。这超出了“历史列表保存在浏览器本地”的范围；服务器是否记录、保留多久，本次无法确认。不愿使用这个第三方检测页时，停在这一依赖步骤，说明原因，只有用户明确改变本次要求后才按新范围处理；执行者不能自行换检测方式并声称完成原流程。不要在这里输入 Claude 密码、验证码或授权码，也不要把带真实地址的检测截图直接公开。

## claude-switcher：感兴趣再了解

可选参考：[YOURSJEYO/claude-switcher](https://github.com/YOURSJEYO/claude-switcher)。它包含账号切换、环境检查和进程看守等功能。其 Windows Beta 版，也就是还在测试阶段的版本，带有一个常驻看守：约每 10 秒检查代理程序或服务以及虚拟网卡状态，发现不符合条件时，强制关闭 Claude 桌面进程。

我们没有在这套环境里安装或使用它，只核对了说明和当前源码。它给读者提供另一种参考，使用前要知道这些区别：

- 它检查的是所设规则，不是所有 Claude 使用条件；看守循环没有逐次验证真实出口或全部泄漏信号。
- 检查有间隔，发现异常后再关闭进程，不能代替防火墙持续阻止意外直连；上游也说明了这个限制。
- 这份 Windows 看守只关闭 Claude 桌面进程，没有保护 AdsPower 网页或 Claude Code 的逻辑。
- 安装和修复可能改动代理配置、系统时区、IPv6 和计划任务；账号切换还会操作 Claude 本地数据。不要直接覆盖已经能正常使用的环境。
- 在所审 Windows 源码里，未发现向作者上传账号资料的实现，但切换会复制整个 Claude 本地数据目录，增加一份未由切换器额外加密的账号副本；出口诊断也会保存在本机。源码还存在备份失败后继续删除当前数据的风险，不能把“没发现外传”理解成可以放心拿现用账号试装。
- 其他平台也要单独判断：macOS 版默认约每 12 小时下载并执行更新后的核心脚本；Linux 版默认归档整份 Chrome／Chromium 用户目录，可能包括其他网站的会话。卸载也可能保留账号快照，不要把它当作只读检测器。

感兴趣可以先读 [Windows 说明](https://github.com/YOURSJEYO/claude-switcher/tree/main/windows) 和 [上游安全说明](https://github.com/YOURSJEYO/claude-switcher/blob/main/SECURITY.md)，备份后在独立环境验证，再自行决定。这里不附安装命令，也不把它作为完成本教程的前提。
