# 哪些电脑适合，遇到问题怎么处理

这套教程按我们用过的 Windows 电脑整理，供你参考。其他电脑要先检查，再决定怎么配；没有实际跑过的组合统一写“待验证”。把 Skill 交给 Codex，可以让它按步骤操作，不等于任何电脑都能一键装好。

Mac 用户先读 [Mac部署流程](Mac部署流程.md)；以下原机配置和 Hyper-V 条件仅针对 Windows 主机，不要求 Mac 存在 D 盘。

## 我们使用的电脑是什么情况

2026-10-26 只读核对了主机系统和虚拟机配置，没有停机、修改网络或重新部署。

| 项目 | 核对结果 |
| --- | --- |
| 主机系统 | Windows 11 专业版，版本 10.0.28000，x64，也就是 Intel／AMD 常见的 64 位架构 |
| 处理器 | AMD Ryzen 7 7800X3D，系统显示 16 个逻辑处理器 |
| 内存 | 约 32 GB，系统可用总量约 31.2 GB |
| 文件位置 | 有可用的 D 盘，任务文件放在 D:\Codex |
| Hyper-V | 已启用；本次核对时原虚拟机正在运行 |
| 虚拟机配置 | 第二代，4 个虚拟处理器，启动内存 4 GB，动态内存范围 4～8 GB |

这些是我们的环境说明，不是最低配置，也不是购买清单。已有虚拟机的内存设置与创建脚本的默认值并不相同。即使电脑总内存够，正在运行的软件也可能把它占满，实际部署前还要看剩余量。配置核对通过也不代表 Claude 当前所有功能都已测过。

## 先判断这台电脑能不能用

下表的系统升级和 Hyper-V 条件针对完整虚拟机路线。只在本机使用 Claude 时，按所选产品的系统要求检查，不因使用本教程就要求家庭版升级专业版。

| 这台电脑的情况 | 怎么处理 |
| --- | --- |
| Windows 11 x64 专业版或企业版 | 继续检查虚拟化、Hyper-V、空闲资源和权限；满足条件才安排安装。其他电脑的整套结果仍待验证。 |
| Windows 11 家庭版 | 先按下节升级专业版并激活，再检查其他条件；不要直接运行 Hyper-V 创建步骤。 |
| Windows 10、教育版或其他 Windows 版本 | 本包未完成整套验证，写“待验证”；核对该版本当前的系统维护状态、Hyper-V 和所选软件支持情况，再决定是否继续。 |
| Mac | 转入 Mac 部署流程，识别 Apple 芯片或 Intel；用 Fusion／已选软件和对应架构镜像，不运行 Hyper-V 脚本。Windows ARM 来宾中的 AdsPower 需先兼容性实测，尚不能保证整套可用。 |
| Linux、Windows ARM 主机，例如部分搭载骁龙的电脑 | 未提供完整部署路线；继续适用的只读检查，不套用 Hyper-V x64 脚本或自行改变方案。 |
| Windows 主机没有 D 盘，或 D 盘不能写入 | 不建议使用这套包，停止部署。不自动改存 C 盘，不为使用教程建议重新分区或格式化。 |
| Windows 主机 D 盘空间不足 | 先由本人清理或扩容；Codex 不自动删除已有文件。创建脚本要求剩余空间至少覆盖虚拟硬盘最大容量再加 10 GB，默认参数即至少 90 GB；还要考虑镜像、更新和备份。 |
| 内存或处理器余量不足 | 保存工作后关闭不需要的程序，再检查；仍不够就不创建。资源按实际余量选，不硬套我们电脑的参数，不自动降低到系统要求以下。 |
| 硬件支持虚拟化，但开机设置里没开启 | 按电脑或主板厂商的官方说明开启。BIOS／UEFI 就是进入 Windows 之前的硬件设置界面，必要操作和重启由本人配合；Codex 可准备对应说明，不承诺能在 Windows 里自动处理。 |
| 硬件不支持所需虚拟化功能 | 本机无法继续这条 Hyper-V 路线；购买专业版许可也不能补上硬件功能。 |
| Hyper-V 尚未启用 | 先说明系统组件改动和可能的主机重启，获得覆盖该项的许可后启用；重启后再读实际状态。 |
| 没有管理员权限，或公司电脑受管理策略限制 | 先联系设备管理员；不能靠脚本绕过权限。 |
| 已有虚拟机、Clash、VPN、AdsPower 或 Claude | 先盘点，确认哪些属于本次任务。能复用就复用，不覆盖同名虚拟机，不把原网络配置换成别人的参数。其他虚拟机或网络软件能否共存，按这台电脑实际验证。 |
| 已有 AdsPower，但没建专用环境或不确定 Claude 从哪里打开 | 分别检查主机和目标来宾。复用安装后继续配置指定环境，从管理界面启动指定环境，先在同一窗口打开指定检测页检查当前出口，再确认 Claude 实际在该窗口打开；不能因为“免重装”跳过整项，也不能用普通浏览器代替。 |
| Codex 只有命令工具，没有浏览器或桌面操作工具 | 能做的检查先做；需要点按钮的步骤列出来由本人操作，或补上经过确认的工具。不能保证只需本人处理登录和付款。 |
| Claude 登录或服务条件不满足、购买资料不完整 | 只暂停依赖它的步骤，说明还缺什么；已授权的独立安装与配置继续，不把所在地问答设为通用配置的入口门槛。若网络改造只为隐藏所在地或绕过服务条件，则不做该改造。 |
| 某个软件的签名或来源核对失败 | 先保留具体检查结果，核对官方来源、签名者及系统判断；暂停该软件与依赖步骤，不关闭校验继续安装，也不凭一句失败提示就断言软件有恶意。 |

微软要求处理器支持相应虚拟化功能，且主机与虚拟机同时有足够内存；见 [Hyper-V 系统要求](https://learn.microsoft.com/en-us/virtualization/hyper-v-on-windows/reference/hyper-v-requirements) 和 [启用说明](https://learn.microsoft.com/en-us/virtualization/hyper-v-on-windows/quick-start/enable-hyper-v)。官方所列 Hyper-V 的基础内存条件，不能当成同时运行 Windows 虚拟机、浏览器和 Claude 的推荐配置。

## 家庭版先升级专业版

家庭版不是永远不能用，但本版完整方案要先补齐版本条件。微软提供 [家庭版升级专业版的官方说明](https://support.microsoft.com/en-us/windows/upgrade-windows-home-to-windows-pro-ef34d520-e73f-3198-c525-d1a218cc2818)。这是“升级版本并激活”，不是只把当前家庭版激活一次。

1. 先在“设置 → 系统 → 激活”查看当前版本和激活状态。Windows 11 家庭版未激活时，先按微软说明处理激活。
2. 没有专业版许可，可以从微软商店购买升级；已有适用且有效的专业版产品密钥，可以按官方流程使用。购买前看清是适用于这台电脑的专业版升级，费用以本人商店页面为准。
3. 付款、微软账号登录和产品密钥输入由本人完成，密钥不发给 Codex、不写进教程或日志。先备份重要文件并保存工作，升级可能需要重启；未经说明不替本人执行升级或重启。
4. 完成后重新检查：版本是否为专业版、激活是否成功、Hyper-V 是否可用。升级专业版不等于 Hyper-V 已开启，也不等于内存和硬件都够用。

不打算购买或无法完成升级，就不建议使用本版完整 Hyper-V 方案。仅在用户另行选择普通安装路线时，再按那个目标处理，不能把它写成同样的隔离效果。

## Codex 动手前要说明什么

先只读检查，再用大白话给本人看这台电脑的情况：

- 系统版本和处理器类型、管理员权限、虚拟化和 Hyper-V 状态。
- 总内存与空闲内存、D 盘是否可写及剩余空间；本次建议给虚拟机多少资源，为什么。
- 已有虚拟机、交换机和相关软件，哪些复用、哪些新增；已经装好的东西不要重复装。
- 哪些条件满足，哪些要先处理，哪些待验证或不适用；若某项读不到就写“未知”，不凭猜测通过。
- 将改哪些系统设置，是否写主机 C 盘、影响网络或需要重启，出问题怎样恢复。

创建脚本默认内存 8 GB、4 个虚拟处理器、最大 80 GB 虚拟硬盘，参数可以调整。实际创建还会检查处理器数量、空闲内存和磁盘空间；它不会自动为所有电脑算出合适配置。先由 Codex 根据现场结果选择参数，再生成计划。

Hyper-V 已经运行时，有些检查会显示“已检测到虚拟机监控程序”，不再显示原来的硬件要求列表。这个提示不能误判成虚拟化不支持；固件字段缺失也要结合现状核对。

## 一键执行前先知道这些风险

教程和 Skill 都只能作为参考。**一键执行有风险，目前也没有在不同电脑上完整验证，不能保证一次成功。**

启用虚拟化组件、安装软件或调整网络和防火墙，可能需要重启、短时断网，或影响已有 VPN、虚拟机及其他软件。虚拟硬盘、系统更新和安装包也会持续占用空间；失败时可能留下半装的程序或虚拟机，需要按记录恢复。

先保存工作，备份要改的配置和重要数据。Codex 先列出计划与影响，按已经得到的授权执行；遇到新的系统升级、主机网络变更或重启，先说明并确认。购买许可和服务另有成本，不能承诺不封号、不泄漏或永远可用。

## 哪些还要标“待验证”

- 换一台电脑从头安装到 Claude 网页、桌面端都能连续聊天。
- 在不同电脑上升级家庭版、启用虚拟化、重启后继续部署的整套流程。
- 不同 Windows 版本、处理器类型，以及其他虚拟机、VPN 或网络软件同时使用的情况。
- 不同供应商的完整采购、服务器配置、网络中断恢复和更新后保护。
- 视频是否逐项讲过这些兼容条件。本次拿到了视频说明，尚未取得完整字幕或文字稿，不能写成“作者没有讲”，也不能借作者的视频保证本包兼容。

“待验证”指还没完成对应实测；Windows 路线没有 D 盘等不满足对应前提的情况，要写“不建议使用”，不能只贴一个“待验证”标签就继续执行。
