# 来宾网络一致性检查

修正版10，更新于 2026-11-07。本节把节点、订阅、保存值与核心当次状态分开核对。检查入口不自动修网络、不下载订阅、不安装解析器、不读取 Windows 登录凭据、不停止核心；只有 -ReadCoreApi 明确启用时，才查询现有本机核心接口。只在选定 Windows 来宾执行，主机结果不能当作来宾证据。

## 运行方法

由 Agent 确认脚本完整路径与来宾身份后，在来宾 PowerShell 执行。无参数只读盘点进程、网卡与防火墙：

    & $GuestNetworkScriptPath

由 Agent 受控准备本地私有 JSON（结构化文本）证据，不把订阅、原始配置或该文件复制进交付包、聊天、公开仓库或报告。脚本将脱敏 JSON 输出到当前进程，不主动写文件：

    & $GuestNetworkScriptPath -EvidencePath $PrivateEvidencePath

可选读取当前核心本机接口，必须明确添加：

    & $GuestNetworkScriptPath -EvidencePath $PrivateEvidencePath -ReadCoreApi

路径变量按目标来宾实际位置赋值。脚本面向 Windows PowerShell 5.1 与 PowerShell 7，管理员终端通常能取得更完整的本机防火墙、监听和进程路径证据；缺权限标未知，不自动提权或申请 Windows 密码。实际兼容性和模拟验证以本版验证记录为准。

## 私有证据字段

字段可省略，缺项对应 unknown（未知）。路径必须是本机绝对路径，不能用网址或 UNC（网络共享）路径。路径、真实地址、组名与配置值只在内存比较，不进入输出。

| 字段 | Agent 应提供的内容 |
| --- | --- |
| core_path | 已确认实际 mihomo 核心完整路径，不填界面或服务管理程序 |
| tun_interface_alias | 已确认属于该核心的实际 TUN 网卡名；只核对网卡状态，不凭名字推断归属 |
| protected_program_paths / protected_package_sids | 本次需要保护的实际程序完整路径数组／Windows 应用包 SID 数组 |
| first_hop | 含 addresses 具体地址数组、port、protocol（TCP/UDP）、interface_alias；必须是实际第一跳，不能用网站出口代替 |
| active_config_path | 正式核心生成并实际使用的活动配置文件 |
| persisted_config_path | Agent 核对过的持久配置源，本地完整配置或受控生成的持久化合并快照；不能用活动文件自身冒充独立来源 |
| verge_config_path | Clash Verge 设置文件，用于读取 enable_dns_override |
| profiles_config_path | 订阅管理文件，用于读取 current 与 items[].selected[] |
| subscription_config_path | 本机保存的原订阅快照，脚本不联网刷新 |
| subscription_checked_at_utc | Agent 当次核实订阅的采集时间，必须含明确 UTC 标记；不凭文件修改时间编造已更新 |
| subscription_max_age_hours | 允许的订阅证据年龄，默认 24 小时；超过时仍需重新受控核实来源 |
| expected_profile_uid / dns_proxy_group | 当前预期配置 UID／主要 nameserver 应指定的代理组名，只供内存比较 |
| node_pairs | 多节点对应数组，每项含 local_node_name、subscription_node_name、persisted_node_name（默认同本地名）、allowed_local_override_fields（默认空数组） |
| local_node_name / subscription_node_name | 保留旧版单节点对应字段；多节点部署优先 node_pairs，覆盖所选链路和可切换候选节点 |
| expected_group_selections | 对象，键为应查组名，值为预期选项 |
| saved_group_selections | 可选对象，同上；未提供时从当前 profiles 条目的 selected[].name/now 读取 |
| runtime_group_selections | 当次受控核心选择快照，同上；旧快照不冒充实时状态 |

node_pairs 只负责明确对应关系，不能凭名字相同就证明内容相同。allowed_local_override_fields 只允许明确审核过的本地运行调整：dialer-proxy、udp、tfo、mptcp、smux、ip-version。服务器、端口、认证、TLS（加密连接参数）、Reality 等不能豁免。即使订阅比对允许上述个别调整，持久源 → 生成活动配置仍严格逐字段比较，不使用豁免，以发现重载后丢失的修复。

证据 JSON 不能自证系统状态。Agent 必须核对文件来源、对应来宾、采集时间、实际核心使用的文件，以及持久源如何生成活动配置。订阅快照新鲜只说明本次提供的采集时间在限额内，不保证供应商节点长期可用；节点不在新订阅中也不单独证明已停用，仍须结合实际连接证据。

配置与证据按 UTF-8 读取。JSON 优先解析，即使扩展名为 .yaml 也能读取 JSON。内容确实是 YAML（代理配置常用文本格式）时，只使用现有 ConvertFrom-Yaml；不存在或失败就标未知，不安装依赖、不靠正则猜字段。不要为检查改写运行文件；需要时由 Agent 受控生成私有 JSON 副本，保留来源说明。

## 可选核心实时只读查询

-ReadCoreApi 从已经解析的 active_config_path 读取现有 external-controller 与 secret。没有另外的 core_api 证据对象，不在命令行传密钥。共享 Read-ClaudeCoreApi.ps1 只允许 127.x.x.x:port 或 [::1]:port 这类回环地址，不接受远程接口；确认监听进程路径与 core_path 相同后，只 GET /configs、/proxies、/connections。它禁用系统代理与重定向，不回显密钥、原始响应、完整连接或真实地址。

默认不查询 API（供程序读取状态的接口）。不为得到证据修改监听地址、不新增或关闭认证、不发送修改配置或代理选择的请求；没有现有解析器、配置、监听身份或权限时保留未知。回环地址只能限制访问位置，仍需检查进程归属；一次当前快照不能保证之后不变。Read-ClaudeCoreApi.ps1 是共享帮助文件，不是独立部署阶段。

## 当次连接与有效设置的狭窄证据

observed_core_first_hop_sockets（核心第一跳连接快照）只读实际核心已建立的 TCP 连接，按指定目标地址与端口匹配。matching_socket_count 大于 0 才记 snapshot_match，否则 unknown；它不发起新请求、不验证出站接口、不检查 UDP，也不能由没有匹配反推连接失败。该结果只证明本次存在匹配连接，不能证明最终请求成功。

runtime_effective_settings（核心当前设置对照）比较活动配置与已验证核心 API 中的 mode、tun.enable。任一明确差异记 fail；没有差异但任一字段缺失记 unknown；两项均有值且一致才记 snapshot_match。接口不提供完整节点认证参数或完整 DNS 配置证明；不要把这两项相同写成整个核心配置完全一致。

## 检查内容与边界

- 当前实际核心路径与输入匹配；指定 TUN 网卡处于 Up。开关本身不能证明流量接管。
- ActiveStore（系统合并后正在生效的防火墙策略）中 Domain、Private、Public 均启用且默认拒绝出站。
- 启用的出站 Allow 结合程序、应用包、用户、服务、地址、端口、协议、接口与网络类别判断；Package 有限定的 Program=Any 不误判为所有程序放行，无法确认服务或用户条件时标未知。
- 核心第一跳最小允许规则与具体地址集合、单一合法端口、协议、出站接口和三类网络范围核对；拒绝 Any、通配符、子网及范围作为第一跳输入。拆分规则或不同表示方式不自动推导等价，交由复核。不能为通过而全放通。
- 复核指定保护程序与应用包是否可绕过 TUN，并查显式 Block（阻止规则）的疑似冲突。复杂条件不自动宣布已穷尽审计，不能擅自删除 Block。
- 活动 UID、预期选择、保存值、快照与可选 API 当次核心状态分别报告。已知保存错误照常 fail，即使实时证据未知也不能掩盖；API 未读取时不能把快照一致写成当前已生效。
- 区分 DNS 覆写与 dns.enable；核对 tun.enable、主要 nameserver 的指定代理组后缀及 UDP/TCP 53 接管。TUN 明确关闭失败，缺字段未知；残留配置不等于正在生效。fallback、nameserver-policy、引导解析、浏览器 DoH 与实际流量仍需受控审查。
- 对 node_pairs 每项逐字段、递归核对活动节点与订阅节点，以及持久源与活动节点；显示 name 不参与内容比较，明确豁免仅限上述审核字段。先验证协议、服务器、合法端口与协议必需认证。支持范围外或信息不足标未知，不把两个空节点判为相同。只返回变化字段名和匹配状态，未知字段名归 other_field，不返回值。

发现问题先保留原始脱敏结果，再由 Agent 在已有授权内私有备份、定点修复并复验。不要先修好再把首次重开或重启写成通过。主机转发另按 [主机与来宾链路复核](主机与来宾链路复核.md) 检查，不因来宾所有文件一致就忽略主机的外层路径。

## 如何解读输出

pass 只代表该行狭窄检查符合证据；snapshot / snapshot_match 表示文件或受控快照；unknown 表示缺信息、无法解析、权限不足或不支持推导；review_required 表示需要继续复核；fail 表示明确不一致。整体只返回 issues_found 或 review_required，不返回全面通过。已知错误不会被其他未知项掩盖。

启用 API 后只对当次读取到的范围说明当前快照；未启用或读取失败仍保留未知。随后仍需同一目标浏览器本次检测、实际停止核心并确认新连接受阻、恢复、来宾重启及所选产品功能验收。DNS 配置与网站本次未报异常是不同证据，均不能保证未来永不泄漏。

在目标来宾运行出口检查前，先从实际配置和供应商资料核对预期住宅出口。-EvidencePath 指向本机私有 JSON，至少填写实际代理核心路径、受保护应用、虚拟网卡名称和物理网卡放行的所有节点接入地址。主用和备用地址可以由多条规则覆盖，端口、协议和网卡必须同属已核对的范围。防火墙地址可写单个 IP，或等效的 IPv4 /32 与 IPv6 /128。

    & $EgressScriptPath -EvidencePath $PrivateEvidencePath -ProxyPort $GuestMixedPort -ExpectedExitIp $ExpectedResidentialIp

脚本先验证防火墙默认拦截、节点放行范围及代理归属，通过才请求 Claude 检测地址。-ExpectedCountry 可选。默认采样 3 次，普通连接失败仍记录并继续，遇到与预期不符的出口则记录后停止。排查间歇卡顿时可加 -RequestCount 60 -IntervalSeconds 6。有本地 D 盘时可加 -SampleLogPath $NewLogPath，其中 $NewLogPath 是 D:\Codex 下尚未存在的 .jsonl 文件，所在目录应已存在。没有 D 盘时，可从宿主机接收脚本最后的脱敏 JSON 并保存到已授权的数据盘。

结果 overall_passed 仅代表这批检测。http_status 为空表示没有记录到 HTTP 响应状态。error_stage 是已知的失败阶段，unknown 表示证据不足。同一个 AdsPower 窗口仍要先打开 https://ip.net.coffee/claude/，再打开 Claude 并独立核对出口和登录。

## 离线行为验证

包根 tests 中的模拟检查使用虚构进程、网卡、防火墙、文件和接口，不访问真实公网、不修改 Windows 策略。本版离线执行结果见《验证记录》及脚本模拟检查结果。模拟验证用于复查判断分支，不能代替真实来宾、网络阻断、订阅更新、主机归属或新电脑验收。
